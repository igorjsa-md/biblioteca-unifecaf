# Biblioteca Digital UniFECAF

Interface web acadêmica, responsiva e acessível para uma biblioteca digital. O projeto foi desenvolvido para a disciplina de Design Web da UniFECAF e usa somente HTML5 e CSS3.

> Este site é uma demonstração acadêmica. Não representa um serviço institucional ativo.

## Objetivo acadêmico

Aplicar semântica HTML, estilização CSS, Grid, Flexbox, responsividade e princípios básicos de acessibilidade na transformação de um protótipo de baixa fidelidade em uma interface moderna.

## Tecnologias

- HTML5;
- CSS3;
- CSS Grid e Flexbox;
- imagens locais em PNG e SVG;
- sem JavaScript, frameworks ou backend.

## Como executar

1. Baixe ou clone este repositório.
2. Abra `biblioteca-unifecaf/index.html` em um navegador moderno.
3. Opcionalmente, no VS Code, use uma extensão de servidor local para atualização automática.

Nenhuma instalação ou compilação é necessária.

## Seções principais

- cabeçalho com navegação interna;
- banner de apresentação;
- apresentação da proposta e quatro benefícios;
- seis cards de livros reais em domínio público;
- três blocos conceituais de unidades;
- contato institucional e rodapé acadêmico.

## Publicação no GitHub Pages

1. Envie a pasta do projeto para um repositório no GitHub.
2. Em **Settings > Pages**, selecione **Deploy from a branch**.
3. Escolha a branch principal e a pasta que contém `index.html`.
4. Salve e aguarde o endereço público ser gerado.

Todos os caminhos são relativos e adequados ao GitHub Pages.
